# Opportunity screen

**Use for:** an initial opportunity shortlist, including federal or verified SLED sources.

Confirm company context, capability, buyer, notice stage, geography, eligibility, response window and available vehicle routes. Search using the actual supported parameters. If the tool cannot filter a requirement, inspect returned records and say how it was checked. Use explicit dates and a bounded result count.

Open candidate records. Report notice type, deadline, relevant scope, documented eligibility, unresolved fit issues and exact returned links. Do not equate sources sought, forecast, RFQ and solicitation stages. A title or NAICS match is evidence for investigation, not proof of fit.

**Prompt:** Find up to five candidates for the confirmed company context and date window. Explain the actual filters used. For each, show evidence of fit, hard conflicts, unknowns, source/date and the next action. If fewer match, return fewer. Do not start analysis or save account changes.

**Return:** notice; agency/office; stage; deadline; fit evidence; disqualifier/unknown; source; next action. State truncation or missing documents. For a SLED portal, retain the issuing agency and returned source link and explain any known registration requirement without registering or paying for the user.
