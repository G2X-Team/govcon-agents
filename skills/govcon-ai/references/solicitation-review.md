# Solicitation and amendment review

**Use for:** document intake, requirements extraction and change tracking.

Inventory the solicitation, attachments, amendments and question-and-answer documents. Keep filename, document ID, version, posting date, source and known controlling relationships. Read complete supported artifacts or all continuation pages. A search passage is not full document coverage. List missing or unreadable material.

Extract requirement, actor, deliverable, due date, evaluation linkage and file/page/section evidence. Separate mandatory text from interpretation. Compare amendments at the requirement level; do not assume every older provision is replaced or that every new upload is an amendment.

**Prompt:** Inventory these files, identify version gaps, then build a cited requirements and amendment matrix. Show previous text, changed text, affected response section, action, owner and unresolved question. Mark the review partial wherever the file set or text is incomplete. Draft only; do not start hosted analysis or claim compliance.

**Return:** coverage inventory, requirement matrix and change log. Recheck the official notice and response instructions before a bid decision or submission. Never silently fix ambiguous legal language.
